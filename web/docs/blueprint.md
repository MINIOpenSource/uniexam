# **App Name**: ClassIsland 考试

## Core Features:

- 试卷展示: 请求并展示试卷。从 `BACKEND_BASE_URL/get_exam` 获取试卷数据，并以友好的方式呈现给用户。
- 答题与提交: 用户作答与提交。允许用户选择答案，并将选择结果以指定格式发送至 `BACKEND_BASE_URL/finish`。
- 结果展示: 结果反馈展示。根据后端返回的不同状态码 (200, 1001, 429)，展示对应的成功、失败或频率限制提示页面。

## Style Guidelines:

- 主色调：淡蓝色 (#00bfff)，作为 ClassIsland 的主题色。
- 成功页面：绿色背景，庆祝考试通过。
- 失败页面：红色背景，提示考试未通过，并提供重考按钮。
- 频率限制页面： нейтральный цвет（如灰色），警告用户达到访问频率限制。
- 试卷页面：清晰、简洁的布局，方便用户阅读题目和选择答案。
